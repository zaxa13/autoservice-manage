# AUTO.WORKS — материалы для лендинга

Документ подготовлен для маркетингового лендинга `auto-works.pro`. Здесь собраны:
ключевые задачи бизнеса, которые решает продукт, сильные стороны и фичи,
со ссылками на скриншоты из живого тенанта.

> Скриншоты собраны автоматически: `app.auto-works.pro`, аккаунт владельца, данные
> за май–июнь 2026. Папка: `screens/`.

---

## 1. Кому это и какую боль закрываем

**Целевая аудитория** — владелец / управляющий независимым автосервисом
(2–15 постов, 2–10 механиков, до ~150 заказ-нарядов в месяц).

**Боль, с которой приходят:**

| Что у клиента сейчас | Что даёт AUTO.WORKS |
| --- | --- |
| Excel-таблицы, тетради записей, заказы на бумаге | Один источник правды: запись → заказ-наряд → оплата → история авто |
| Не знаю, сколько реально заработали в этом месяце | Дашборд с выручкой, маржой, средним чеком и сравнением с прошлым периодом |
| Механики «забыли» половину работ — теряем выручку | Каждая работа фиксируется в заказ-наряде с автором и ценой |
| Зарплата считается на калькуляторе с риском ошибки | Авторасчёт по схемам: % от работ, % от заказов, фиксированный оклад |
| Запчасти исчезают со склада «как-то сами» | Журнал движений + автосписание при оплате заказа |
| Запись клиентов в WhatsApp — пропускаем, путаемся в постах | Канбан-доска записей по постам и временным слотам, drag-and-drop |
| Не помню, что делали этой машине прошлый раз | История по автомобилю и клиенту с одного клика |

---

## 2. Главный посыл (для hero-блока)

> **AUTO.WORKS — операционная система автосервиса.**
> Все записи, заказ-наряды, склад, зарплата и аналитика в одном окне.
> Видите выручку, маржу и загрузку механиков в реальном времени.

Альтернативные подзаголовки:
- «Перестаньте управлять автосервисом по тетрадке».
- «От записи до выплаты механику — за один сеанс».
- «Понятная аналитика без бухгалтера и без 1С».

## 3. Сильные стороны (ключевые блоки лендинга)

### 3.1 Сильная управленческая аналитика
*Не «оборот красивыми циферками», а реальная картина бизнеса.*

- KPI-карточки: поступления, выручка, средний и медианный чек, кол-во закрытых заказов
- Сравнение с прошлым периодом (день/неделя/месяц/квартал/год)
- **Маржа по работам и запчастям** отдельно — видна реальная прибыль, а не оборот
- Доля работ в выручке (показывает «правильный» микс работы / запчасти)
- Прогноз выручки на месяц / год при текущем темпе
- Алерты «требует внимания»: зависшие в работе заказы, заказы без механика

**Скриншоты:**
- `screens/01-dashboard-year.png` — дашборд за год (выручка 1 266 300 ₽, маржа 70 % по работам, 99 % по запчастям)
- `screens/07-reports-revenue.png` — отчёт по выручке (динамика по дням, методы оплаты, категории работ)
- `screens/08-reports-mechanics.png` — отчёт по механикам (выработка, доля, средний чек, ФОТ)
- `screens/09-reports-parts.png` — отчёт по запчастям (топ по выручке, маржинальность)

---

### 3.2 Канбан-доска записей с drag-and-drop
*Самый «продаваемый» визуальный блок лендинга.*

- Расписание по **постам** (рабочим местам) и временным слотам
- Виды: **день** (детально) и **неделя** (обзор загрузки)
- Цвета по статусам: Записан → Подтверждён → Авто на СТО → В работе → Готов → Завершён
- Перетаскивание карточек между слотами (библиотека `@dnd-kit`)
- Из любой записи — один клик до **создания заказ-наряда**
- Карточка показывает: клиент, телефон, авто (марка/модель/гос.номер), время

**Скриншоты:**
- `screens/02-appointments-week-kanban.png` — неделя, цветовая карта загрузки
- `screens/03-appointments-day-dnd.png` — день, draggable-карточки с быстрой сменой статуса

---

### 3.3 Заказ-наряды: вся работа сервиса в одном экране

- Полная карточка: авто (VIN, гос.номер, пробег), клиент, менеджер, механик, статус
- **Работы**: добавление из каталога или «на лету», цена / кол-во / скидка / автор-механик
- **Запчасти**: поиск по артикулу, автосписание со склада при оплате
- **Платежи**: наличные / карта, частичная оплата, история, отмена платежа
- Глобальная скидка на весь заказ
- **Печать**: заказ-наряд и акт выполненных работ
- Рекомендации клиенту + внутренние комментарии для мастеров
- Список заказов с фильтрами по статусу, периоду, поиском по номеру/клиенту/гос.номеру/мастеру
- Сортировка и пагинация (145 заказов в демо-данных)

**Скриншоты:**
- `screens/04-orders-list.png` — список заказ-нарядов с фильтрами и табами статусов
- `screens/05-order-detail.png` — детальная карточка заказа со всеми блоками

### 3.4 Информационная касса
*Удобный обзор денег. Это **не** финансовая отчётность и не онлайн-касса по 54-ФЗ — мы не финансовая организация. Это операционная сводка по поступлениям и счетам сервиса.*

- Общий остаток по всем счетам
- Несколько счетов (наличные / банк / другие), архивирование счетов
- Приход / расход / чистый поток за период
- Лента всех операций: дата, тип, счёт, категория, описание, сумма
- Автозаведение операции при оплате заказ-наряда (привязка к ЗН)
- Фильтры по периоду (день/вчера/неделя/месяц/год/произвольный), счёту, типу операции
- Табы: все операции / приходы / расходы / переводы

**Скриншоты:**
- `screens/06-cashflow.png` — касса за год с лентой приходов по ЗН

> ⚠ Юридическая формулировка для лендинга:
> «AUTO.WORKS не является финансовой или платёжной организацией.
> Раздел «Касса» — внутренний учётный инструмент для владельца сервиса,
> не заменяет ККТ и не предназначен для фискализации операций».

### 3.5 Зарплата механиков на автопилоте

- **Схемы оплаты**: фиксированный оклад + % от работ, % от всех заказов, фикс на заказ
- Автоматический расчёт за период (день/неделя/месяц/произвольный)
- Привязка ко всем закрытым работам мастера за период
- Учёт штрафов и бонусов
- Статусы расчёта: Рассчитана → Выплачена (с привязкой к счёту в кассе)
- Выплата прямо из интерфейса (с автозаписью в кассу)

**Скриншот:**
- `screens/11-salary.png` — расчёты по механикам за май 2026

---

### 3.6 Склад и движение запчастей

- Остатки с минимальным порогом и местом хранения (стеллаж / полка)
- Журнал движений: поступление, расход (списание в заказ), корректировка
- Приходные накладные от поставщика
- Поиск по артикулу с нормализацией (пробелы и регистр)
- Отдельная вкладка «**Низкий остаток**» — что закупать
- Сверка с поставщиком (отдельный модуль)

**Скриншот:**
- `screens/10-warehouse.png` — таблица остатков

### 3.7 База клиентов и автомобилей с историей

- Карточка клиента: ФИО, телефон, email, адрес, теги
- Карточка автомобиля: марка/модель, год, гос.номер, VIN, пробег
- **Сменить владельца** — машина переходит к другому клиенту с сохранением истории
- История обслуживания по машине (все ЗН одним списком)
- Поиск по ФИО / телефону / гос.номеру / VIN

**Скриншоты:**
- `screens/12-vehicles.png` — карточки авто с VIN, пробегом, владельцем

## 6. Возражения и ответы (для FAQ-блока)

| Возражение | Ответ |
| --- | --- |
| «У меня уже 1С / Excel» | Не нужно ставить, обучать бухгалтера, тратить часы. AUTO.WORKS — это рабочее место менеджера и владельца, открыл и работаешь |
| «Касса — это же 54-ФЗ?» | Нет. Это внутренний учёт денежного потока, не фискализация. ККТ-чек выбивайте как привыкли |
| «У меня свой айтишник» | AUTO.WORKS — SaaS. Не нужны сервера, обновления, бэкапы — мы это делаем |
| «А если интернет отвалится?» | Работает в браузере, тёплый кэш + переподключение. Запись и заказ-наряд не теряются |
| «Сложно для механиков» | Механик видит только свои заказы и переключает статусы. Минимум кликов |

## 7. Структура лендинга (рекомендация)

1. **Hero** — заголовок, подзаголовок, скриншот дашборда, CTA «Попробовать»
2. **Боль / решение** — 3 колонки «было / стало»
3. **Канбан-блок** (3.2) — самый «вау», большой скриншот
4. **Заказ-наряды** (3.3) — закрывает 80 % рутины
5. **Аналитика** (3.1) — для владельца, который хочет видеть прибыль
6. **Касса + Зарплата + Склад** — троица операционных модулей (компактные карточки)
7. **Клиенты и авто** (3.7) — про повторные продажи
8. **Stats** — цифры из п. 5
9. **FAQ** — п. 6
10. **CTA + футер**
